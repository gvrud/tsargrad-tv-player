> **Неофициальное приложение для личных нужд. Не для распространения.**

> в магазинах приложений или коммерческого использования.

Полноэкранный клиент прямого эфира телеканала «Царьград ТВ» для Android 8–16.
Источник выбирается между RuTube и VK Video. Приложение не использует Google Services.

## Что умеет

- Сразу запускает эфир и уходит в полноэкранный режим: скрывает системные панели, учитывает вырез экрана, удерживает экран включённым.
- Играет HLS-поток через Media3/ExoPlayer. RuTube отдаёт master-плейлист с вариантами 360p/720p/1080p — Adaptive Bitrate автоматически переключает качество под скорость сети.
- Показывает текущее выбранное разрешение в бейдже «АВТО · 720p» и обновляет его при переключении ABR.
- Переключает источник RuTube / VK Video на лету, запоминает выбор.
- Кнопка «Слушать аудио» отключает видеодорожку, не останавливая звук; экран сменяется оверлеем «Только аудио». Повторное нажатие возвращает видео.
- При обрыве потока заново получает свежий HLS-URL (токены RuTube живут ограниченно) и делает до трёх попыток с паузой. Если не удалось — показывает понятную ошибку с кнопками «Повторить» и «Попробовать другой источник».
- Не содержит рекламы, аналитики, аккаунтов и Google Play Services.

## Сборка

Требования: JDK 17, Android SDK с платформой 36. Android Studio или командная строка.

```bat
gradlew.bat assembleDebug
```

На Linux/macOS:

```bash
./gradlew assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.
Проверка кода: `gradlew.bat lintDebug`.

Проект собран и проверен с AGP 8.13.2, Gradle 8.14.3, Kotlin 2.2.20,
Media3 1.11.1. Wrapper уже в репозитории, при первой сборке Gradle скачает дистрибутив.

Для release-сборки добавьте свой keystore и `signingConfig` в `app/build.gradle.kts`.
Сейчас release не минифицируется.

## Источники

Все идентификаторы собраны в `Streams.kt`.

### RuTube (основной, проверенный)

- ID эфира: `91815da4edb167b5bd617bae490e57da`
- Канал: `23488009`
- Страница: <https://rutube.ru/live/video/91815da4edb167b5bd617bae490e57da>

Резолвер запрашивает:

```text
https://rutube.ru/api/play/options/<LIVE_ID>/?format=json
```

и берёт `live_streams.hls[] .url`. На 18.11.2026 API вернул master-плейлист
`index.m3u8` с вариантами 640×360, 1280×720 и 1920×1080. Если API недоступен,
приложение парсит HLS-ссылку из HTML страницы эфира или embed-страницы.

HLS-запросы идут с браузерным User-Agent, `Referer: https://rutube.ru/` и
`Origin: https://rutube.ru`, чтобы CDN не блокировал нативный плеер.

### VK Video (альтернативный)

- Owner ID: `-75679763`
- Video ID: `456337658`
- `VK_HASH`: пусто

Резолвер пробует `video_ext.php` на `vk.com`, `m.vk.com` и `vkvideo.ru`,
затем ищет HLS-URL в `playerParams`. Если в коде вставки трансляции есть
параметр `hash`, укажите его в `Streams.VK_HASH` — он будет добавлен к запросу.

Важно: из сети, где собирался проект, VK отдаёт страницу входа вместо
embed-плеера, поэтому HLS-путь VK не удалось проверить end-to-end. На
пользовательском устройстве публичный embed может работать; если VK
потребует авторизацию или hash, используйте RuTube. Архитектура позволяет
заменить `VK_OWNER_ID`/`VK_VIDEO_ID` на актуальную трансляцию без правок кода.

## Как это устроено

- `MainActivity.kt` — экран, immersive-режим, управление ExoPlayer, ABR, аудио-режим, авто-повторы, ошибки.
- `StreamResolver.kt` — HTTP-клиент, разбор JSON/HTML, извлечение `.m3u8`, выбор master-плейлиста.
- `Streams.kt` — ID трансляций, User-Agent и Referer.
- `PlayerPrefs.kt` — выбранный источник и аудио-режим.
- Media3: `media3-exoplayer`, `media3-exoplayer-hls`, `media3-ui`.

ABR включён по умолчанию в `DefaultTrackSelector`; сверху стоит ограничение
1920×1080 и 9 Мбит/с, чтобы не тянуть 4K на телефоне.

Аудио-режим реализован через:

```kotlin
trackSelectionParameters = trackSelectionParameters.buildUpon()
    .setTrackTypeDisabled(C.TRACK_TYPE_VIDEO, true)
    .build()
```

Видеодекодер отключается, звук продолжает играть, поверх видео показывается
непрозрачный оверлей.

## Ограничения

- **Фоновая работа.** Приложение не поднимает foreground service: при уходе
  в фон или выключении экрана `onStop` ставит эфир на паузу. Пока приложение
  открыто, экран удерживается включённым. Для фонового радио нужен
  `MediaSessionService`, его здесь сознательно нет, чтобы не усложнять сборку.
- **Трафик в аудио-режиме.** В master-плейлисте RuTube варианты идут с
  muxed audio+video, отдельной audio-only дорожки нет. Режим убирает картинку
  и видео-декодер, но сегменты могут по-прежнему содержать видео. Обещать
  кратное снижение трафика нельзя; если источник отдаст отдельную аудиодорожку,
  ExoPlayer выберет её.
- **VK.** См. выше: возможны требования hash/авторизации, проверка ограничена.
- **Хрупкость парсинга.** RuTube/VK меняют разметку и API. Резолвер имеет
  несколько запасных путей, но при изменениях платформ может понадобиться
  обновить `StreamResolver.kt`/`Streams.kt`.
- **Права на контент.** Приложение не содержит и не распространяет видео,
  не обходит DRM и гео-ограничения. Оно лишь воспроизводит публично доступные
  эфиры; права принадлежат телеканалу.
